## 2024-05-24 - Cached Intl.DateTimeFormat vs Moment.js\n**Learning:** Instantiating new `Intl.DateTimeFormat` objects inside a React component render loop is expensive. Although native, it has non-trivial initialization overhead. Benchmarks show that caching a single instance outside the component scope is roughly 78x faster than re-instantiating it or using `moment.js` during every render.\n**Action:** When replacing heavy date libraries like `moment.js` with native `Intl.DateTimeFormat` in React applications, always instantiate the formatter object outside of the component or use `useMemo` if dynamic locales are required, to prevent performance regressions from garbage collection and re-initialization.
