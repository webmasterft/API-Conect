## 2023-10-14 - Replace moment.js with cached Intl.DateTimeFormat
**Learning:** Benchmarking confirmed that caching 'Intl.DateTimeFormat' instances outside of React components is approximately 35x faster than re-instantiating them during every render cycle, and ~5.8x faster than using moment.js.
**Action:** Always prefer native `Intl` APIs for date/time formatting over large libraries like `moment.js` when bundle size and performance are critical. When using `Intl.DateTimeFormat` in React components, always declare the instance outside the component function to avoid expensive re-instantiation during every render cycle. When parsing date strings from APIs (format 'YYYY-MM-DD HH:mm:ss') using the `Date` constructor, remember to replace hyphens with forward slashes (`.replace(/-/g, "/")`) to ensure cross-browser compatibility.
