## 2026-03-18 - Native Intl.DateTimeFormat vs Moment.js\n**Learning:** The `moment.js` library is a massive dependency that significantly bloats bundle sizes and slows down the application. It is especially heavy when only simple date formatting is required.\n**Action:** Use the native `Intl.DateTimeFormat` API for date formatting instead. When dealing with cross-browser compatibility, replace hyphens with forward slashes in date strings (e.g., `.replace(/-/g, "/")`) before parsing them with the `Date` constructor.
