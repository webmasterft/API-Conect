## 2024-10-24 - Faster Date Formatting with Intl.DateTimeFormat
**Learning:** In React components that render lists (like `cards.js` mapping over weather data), creating a new `moment` instance and formatting it on every render cycle is a significant performance bottleneck. Benchmarking showed `moment(d).format("dddd")` taking ~700ms vs a cached `Intl.DateTimeFormat` instance taking ~84ms for 50,000 operations (~8x faster).
**Action:** When basic date formatting is required in render loops, cache an `Intl.DateTimeFormat` instance outside the component rather than relying on heavy libraries like `moment.js` or re-instantiating formatters inside the loop. Remember to replace hyphens with slashes in API date strings before passing them to the native `Date` constructor for broad browser compatibility.
