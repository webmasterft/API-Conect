## 2024-05-18 - Avoid re-instantiating Intl.DateTimeFormat inside render loops
**Learning:** Initializing `Intl.DateTimeFormat` is an expensive operation in JavaScript. Creating a new instance inside a React component (like `Card`) causes it to be re-instantiated on every render, leading to unnecessary overhead, especially when rendering lists of items. Also, when using native `Date` parsing on string like 'YYYY-MM-DD HH:mm:ss', browsers like Safari can fail to parse it if hyphens are used; replacing hyphens with slashes (`.replace(/-/g, "/")`) ensures cross-browser compatibility.
**Action:** Always instantiate `Intl.DateTimeFormat` objects outside of React component functions if the formatting options are static. Replace hyphens with slashes when parsing date strings using the `Date` constructor to avoid cross-browser parsing bugs.
