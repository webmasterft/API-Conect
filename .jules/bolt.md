## 2024-05-18 - Replacing moment.js with native Intl API for performance
**Learning:** Instantiating `moment.js` and formatting dates inside a render loop can be a significant performance bottleneck, especially for lists. Benchmarking confirmed that caching an `Intl.DateTimeFormat` instance outside of React components is significantly faster (orders of magnitude) than re-instantiating it during every render cycle or using `moment.js`.
**Action:** When formatting dates, prefer the native `Intl.DateTimeFormat` API over heavy libraries like `moment.js`. Always cache the formatter instance outside the component to prevent re-instantiation on every render. Be mindful of cross-browser compatibility issues (e.g., replacing hyphens with slashes in date strings before passing them to the `Date` constructor).
