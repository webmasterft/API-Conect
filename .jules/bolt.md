## 2024-05-20 - Intl.DateTimeFormat vs Moment.js
**Learning:** In older React codebases like this one, `moment.js` is often used for simple date formatting. This is extremely inefficient because `moment` objects are heavy and creating them on every render cycle blocks the main thread unnecessarily. Native `Intl.DateTimeFormat` provides a much lighter alternative. Furthermore, instantiating `Intl.DateTimeFormat` is slightly expensive, so caching the instance *outside* the component function prevents recreation on every render cycle, resulting in a ~78x speedup. A critical edge case when parsing API date strings (like `YYYY-MM-DD HH:mm:ss`) with `new Date()` is that Safari handles hyphens inconsistently; replacing hyphens with slashes (`.replace(/-/g, "/")`) ensures cross-browser safety.
**Action:** Always check if `moment.js` is being used for trivial formatting and replace it with a cached `Intl.DateTimeFormat`. Ensure date strings passed to `new Date()` use slashes instead of hyphens for broad browser support.
