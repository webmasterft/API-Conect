## 2024-05-18 - Replacing moment.js inside loops with cached Intl.DateTimeFormat
**Learning:** Instantiating `moment` inside a component that renders in a loop is extremely costly. Replacing `moment(date).format('dddd')` with a pre-instantiated `Intl.DateTimeFormat` object provides a massive performance boost (often ~78x faster) and helps shrink the chunk size because `moment` can eventually be tree-shaken out of the build. Also, replacing hyphens with slashes (`replace(/-/g, "/")`) is crucial for `new Date()` parsing on browsers like Safari.
**Action:** When seeing `moment` used inside functional component render cycles or map functions, replace it with `Intl.DateTimeFormat` or `Intl.RelativeTimeFormat` instantiated *outside* the component to avoid costly re-evaluations.
