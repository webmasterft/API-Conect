## 2023-10-24 - Cached Intl.DateTimeFormat vs Moment.js
**Learning:** Caching an `Intl.DateTimeFormat` instance outside of a React component is significantly faster than using `moment.js` or re-instantiating `Intl.DateTimeFormat` during every render cycle. When parsing standard string dates (like those from OpenWeatherMap) across browsers using the native `Date` constructor, replacing hyphens with forward slashes (e.g., `.replace(/-/g, "/")`) is crucial for cross-browser compatibility (especially for Safari).
**Action:** Default to using native `Intl` APIs for date formatting where possible, cache the formatter instances outside of the component render loop, and ensure cross-browser date parsing correctness by replacing hyphens with slashes if parsing ISO-like date strings manually.
