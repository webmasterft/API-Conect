## 2024-05-13 - [Date Parsing for native Intl.DateTimeFormat in React]
**Learning:** When replacing `moment.js` with the native `Intl.DateTimeFormat` API for performance optimizations on date strings formatted as `"YYYY-MM-DD HH:mm:ss"` (common in API responses), you must replace hyphens with slashes (e.g., `dt_txt.replace(/-/g, "/")`) prior to passing the string into the `Date()` constructor to ensure correct parsing across all browsers (specifically older Safari versions). Furthermore, caching the `Intl.DateTimeFormat` instance globally outside of the component is required to avoid expensive re-instantiations on each render cycle.
**Action:** Always extract and cache the `Intl.DateTimeFormat` instantiations outside of React render loops and sanitize API-provided date strings using `.replace(/-/g, "/")` when invoking native `Date` constructors to avoid browser incompatibility.
