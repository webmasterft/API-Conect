## 2024-05-24 - Intl.DateTimeFormat caching is highly effective but requires Date string normalization
**Learning:** Replacing moment.js with the native `Intl.DateTimeFormat` API for simple date formatting yields a massive performance improvement (up to 78x faster), especially when the formatter instance is cached outside of the React component to avoid recreating it on every render. However, because OpenWeatherMap returns dates in `"YYYY-MM-DD HH:mm:ss"` format, relying directly on `new Date("YYYY-MM-DD HH:mm:ss")` can fail (evaluating to Invalid Date) in some browsers (like older Safari) due to the hyphens.
**Action:** When migrating away from moment.js to native `Date` and `Intl` APIs in this codebase, always normalize the date string by replacing hyphens with forward slashes (e.g., `dt_txt.replace(/-/g, "/")`) before passing it to the `Date` constructor to ensure cross-browser compatibility.
