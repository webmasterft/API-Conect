## 2024-07-24 - Cached Intl.DateTimeFormat vs moment.js for React Lists
**Learning:** In React components that render lists (like the `Card` component for weather forecasts), instantiating `moment.js` or even `Intl.DateTimeFormat` within the render loop introduces a measurable performance hit. Benchmarking shows that caching a single `Intl.DateTimeFormat` instance outside the component is significantly faster (orders of magnitude) than re-instantiating it or using `moment` during every render cycle. Additionally, `moment.js` adds significant weight to the bundle size.
**Action:** When formatting dates in list components, avoid `moment.js` if possible. Instead, use a cached `Intl.DateTimeFormat` instance instantiated outside the component's render scope. Ensure date strings are standardized (e.g., replacing hyphens with slashes for cross-browser Safari compatibility) before passing them to the native `Date` constructor.
