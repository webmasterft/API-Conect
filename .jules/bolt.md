## 2024-05-24 - Native Date Formatting Performance
**Learning:** In React components, using the native `Intl.DateTimeFormat` API is significantly more performant than importing heavy libraries like `moment.js` just for simple formatting tasks like extracting the day of the week. Additionally, moving the instantiation of the formatter outside of the component function prevents expensive re-allocation during every render cycle. When creating native `Date` objects from OpenWeatherMap strings, replacing hyphens with slashes (`replace(/-/g, "/")`) is crucial for cross-browser parsing compatibility.
**Action:** Default to `Intl.DateTimeFormat` over `moment.js` for date formatting, always initialize formatter instances outside the render loop, and apply the slash-replacement trick for raw date strings.
