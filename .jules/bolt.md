## 2026-06-10 - Date Formatting Optimization\n**Learning:** Instantiating `Intl.DateTimeFormat` or using `moment` within a React component's render function (like mapping over weather forecast items in `Card`) causes significant performance overhead due to repeated expensive parsing and formatting operations on every render.\n**Action:** Always cache `Intl.DateTimeFormat` instances outside of the component scope to ensure it's only created once, and replace heavy libraries like `moment` with native APIs when simple formatting is all that's required.
