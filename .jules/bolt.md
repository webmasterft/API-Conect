## 2024-05-19 - Caching Intl.DateTimeFormat vs Moment.js
**Learning:** Instantiating `Intl.DateTimeFormat` on every render for date formatting (like replacing `moment.js` usage in React components) can be surprisingly expensive. However, caching a single instance of `Intl.DateTimeFormat` outside of the component reduces this overhead to virtually zero, making it orders of magnitude faster than both recreating it and using a heavy library like `moment`. Note: When parsing 'YYYY-MM-DD HH:mm:ss' strings, replace hyphens with slashes (`.replace(/-/g, "/")`) before passing them to the JS `Date` constructor to ensure cross-browser compatibility.
**Action:** When replacing moment.js with native `Intl` APIs in loops or functional components, always cache the `Intl.DateTimeFormat` object outside the render function/component scope.
